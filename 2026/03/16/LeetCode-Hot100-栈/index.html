20. 有效的括号

题目链接：20. 有效的括号

解题思路

核心思想：利用栈的”后进先出”特性，匹配括号。

算法流程：

  1. 如果字符串长度是奇数，直接返回false
  2. 遍历字符串：
    • 遇到左括号：入栈
    • 遇到右括号：检查栈顶是否匹配，匹配则出栈，不匹配则返回false
  3. 遍历结束后，栈必须为空才有效

三种写法思路：

  • 写法一：哈希表存储右括号→左括号映射，遇到右括号时检查栈顶是否等于对应左括号
  • 写法二：哈希表存储左括号→右括号映射，遇到左括号时入栈对应的右括号，遇到右括号时检查是否与栈顶相等
  • 写法三：不用哈希表，直接用if-else判断，遇到左括号入栈对应右括号

155. 最小栈

题目链接：155. 最小栈

前置知识：关于 emplace 和 push

在 C++ 里， stack::emplace 是用来直接在栈顶“原地构造”元素的函数，比 push 更高效。

一、基本作用

  • stack 的成员函数，C++11 起支持
  • 功能：在栈顶直接构造对象，不产生临时对象、不拷贝/移动
  • 用法：把构造函数的参数直接传给 emplace

二、和 push 的区别

  • push：传已经建好的对象，可能拷贝/移动
  • emplace：传构造参数，原地构造，少一次拷贝/移动

对 复杂对象（string、自定义类），emplace 明显 更优。

解题思路

核心思想：使用栈存储数值和当前最小值的配对，每次入栈时记录当前最小值。

算法流程：

  1. 初始化栈，压入哨兵元素 [0, INT_MAX]（0为占位值，INT_MAX为初始最小值）
  2. push：将 [value, min(getMin(), value)] 压入栈
  3. pop：弹出栈顶元素
  4. top：返回栈顶元素的第一个值（数值）
  5. getMin：返回栈顶元素的第二个值（最小值）

关键点：

  • 栈中每个元素都是一个pair，包含当前值和当前最小值
  • 哨兵元素避免栈空判断，简化代码

394. 字符串解码

题目链接：394. 字符串解码

解题思路

核心思想：使用栈保存遇到 [ 之前的状态（已解码字符串和重复次数），遇到 ] 时弹出状态并重复当前字符串。

算法流程：

  1. 遍历字符串每个字符：
    • 字母：直接追加到结果字符串
    • 数字：累积计算重复次数（考虑多位数）
    • **[**：将当前结果字符串和数字压入栈，然后重置结果和数字
    • **]**：弹出栈顶状态，将当前结果重复对应次数后追加到之前的结果后
  2. 返回最终解码字符串

关键点：

  • 数字可能是多位数，需要累积计算 k = k * 10 + (c - '0')
  • 遇到 [ 时保存状态，遇到 ] 时恢复状态并处理重复

739. 每日温度

题目链接：739. 每日温度

解题思路

核心思想：使用单调栈（递减栈）记录未找到更高温度的天数索引。

算法流程：

  1. 初始化结果数组，全部为0
  2. 遍历温度数组：
    • 当栈不为空且当前温度 > 栈顶索引对应的温度时：
      • 弹出栈顶索引 j
      • 设置 ans[j] = i - j（当前天数 - 栈顶天数）
    • 将当前索引 i 压入栈
  3. 返回结果数组

关键点：

  • 单调栈中存储的是索引，不是温度值
  • 栈始终保持递减顺序：栈顶是最近的未找到更高温度的天数
  • 遇到更高温度时，弹出所有比当前温度低的索引并计算天数差

70. 爬楼梯

题目链接：70. 爬楼梯

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i]：到达第 i 阶楼梯的方法数

2. 确定递推公式

  • 第 i 阶楼梯可以从第 i-1 阶或第 i-2 阶到达
  • dp[i] = dp[i-1] + dp[i-2]

3. dp 数组的初始化

  • dp[1] = 1：只有 1 阶楼梯，只有 1 种方法
  • dp[2] = 2：有 2 阶楼梯，有 2 种方法（1+1 或 2）

4. 确定遍历顺序

  • 从前往后遍历，因为 dp[i] 依赖于 dp[i-1] 和 dp[i-2]

5. 举例推导 dp 数组

  • 当 n = 5 时：
    • dp[1] = 1
    • dp[2] = 2
    • dp[3] = dp[2] + dp[1] = 3
    • dp[4] = dp[3] + dp[2] = 5
    • dp[5] = dp[4] + dp[3] = 8

118. 杨辉三角

题目链接：118. 杨辉三角

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i][j]：杨辉三角第 i 行第 j 列的元素值

2. 确定递推公式

  • 每行首尾元素为 1
  • 中间元素：dp[i][j] = dp[i-1][j-1] + dp[i-1][j]

3. dp 数组的初始化

  • dp[0][0] = 1：第一行只有一个元素 1
  • dp[i][0] = 1 和 dp[i][i] = 1：每行首尾为 1

4. 确定遍历顺序

  • 从第 2 行开始，逐行从左到右计算

5. 举例推导 dp 数组

  • 当 numRows = 5 时：
    • 第 0 行：[1]
    • 第 1 行：[1, 1]
    • 第 2 行：[1, 2, 1]
    • 第 3 行：[1, 3, 3, 1]
    • 第 4 行：[1, 4, 6, 4, 1]

198. 打家劫舍

题目链接：198. 打家劫舍

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i]：考虑前 i 间房屋（索引 0 到 i），能偷窃到的最高金额

2. 确定递推公式

  • 对于第 i 间房屋，有两种选择：
    • 不偷：dp[i] = dp[i-1]
    • 偷：dp[i] = dp[i-2] + nums[i]
  • 取最大值：dp[i] = max(dp[i-1], dp[i-2] + nums[i])

3. dp 数组的初始化

  • dp[0] = nums[0]：只有一间房屋，只能偷它
  • dp[1] = max(nums[0], nums[1])：两间房屋，选金额大的

4. 确定遍历顺序

  • 从前往后遍历，因为 dp[i] 依赖于 dp[i-1] 和 dp[i-2]

5. 举例推导 dp 数组

  • 当 nums = [1, 2, 3, 1] 时：
    • dp[0] = 1
    • dp[1] = max(1, 2) = 2
    • dp[2] = max(2, 1+3) = 4
    • dp[3] = max(4, 2+1) = 4

279. 完全平方数

题目链接：279. 完全平方数

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i]：组成数字 i 所需的最少完全平方数个数

2. 确定递推公式

  • 对于每个数 i，尝试所有可能的完全平方数 j*j
  • dp[i] = min(dp[i], dp[i - j*j] + 1)

3. dp 数组的初始化

  • dp[0] = 0：组成 0 需要 0 个完全平方数
  • 其他 dp[i] = n + 1：初始化为一个较大值，表示未计算

4. 确定遍历顺序

  • 外层遍历完全平方数（物品），内层遍历目标值（背包）
  • 完全背包问题，先遍历物品再遍历背包

5. 举例推导 dp 数组

  • 当 n = 12 时：
    • dp[0] = 0
    • dp[1] = dp[0] + 1 = 1
    • dp[2] = dp[1] + 1 = 2
    • dp[3] = dp[2] + 1 = 3
    • dp[4] = min(dp[3]+1, dp[0]+1) = 1
    • dp[12] = 3（4+4+4）

322. 零钱兑换

题目链接：322. 零钱兑换

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i]：凑成金额 i 所需的最少硬币个数

2. 确定递推公式

  • 对于每个硬币 coin，尝试使用它
  • dp[i] = min(dp[i], dp[i - coin] + 1)

3. dp 数组的初始化

  • dp[0] = 0：凑成金额 0 需要 0 个硬币
  • 其他 dp[i] = amount + 1：初始化为一个较大值，表示不可能

4. 确定遍历顺序

  • 外层遍历硬币（物品），内层遍历金额（背包）
  • 完全背包问题，求最少硬币数

5. 举例推导 dp 数组

  • 当 coins = [1, 2, 5], amount = 11 时：
    • dp[0] = 0
    • dp[1] = dp[0] + 1 = 1
    • dp[2] = min(dp[1]+1, dp[0]+1) = 1
    • dp[5] = 1
    • dp[11] = min(dp[10]+1, dp[9]+1, dp[6]+1) = 3（5+5+1）

300. 最长递增子序列

题目链接：300. 最长递增子序列

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i]：以 nums[i] 结尾的最长递增子序列的长度

2. 确定递推公式

  • 对于每个 i，遍历所有 j < i：
    • 如果 nums[i] > nums[j]，则 dp[i] = max(dp[i], dp[j] + 1)

3. dp 数组的初始化

  • dp[i] = 1：每个元素本身就是一个长度为 1 的递增子序列

4. 确定遍历顺序

  • 外层从左到右遍历 i，内层遍历 j 从 0 到 i-1

5. 举例推导 dp 数组

  • 当 nums = [10, 9, 2, 5, 3, 7, 101, 18] 时：
    • dp[0] = 1
    • dp[1] = 1（9 < 10）
    • dp[2] = 1（2 < 9, 2 < 10）
    • dp[3] = dp[2] + 1 = 2（5 > 2）
    • dp[4] = dp[2] + 1 = 2（3 > 2）
    • dp[5] = max(dp[2]+1, dp[3]+1, dp[4]+1) = 3（7 > 2, 7 > 5, 7 > 3）
    • 最终答案：4

53. 最大子数组和

题目链接：53. 最大子数组和

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i]：以 nums[i] 结尾的最大子数组和

2. 确定递推公式

  • 对于第 i 个元素，有两种选择：
    • 加入前面的子数组：dp[i-1] + nums[i]
    • 从当前元素重新开始：nums[i]
  • dp[i] = max(dp[i-1] + nums[i], nums[i])

3. dp 数组的初始化

  • dp[0] = nums[0]：第一个元素本身就是最大子数组

4. 确定遍历顺序

  • 从前往后遍历，因为 dp[i] 依赖于 dp[i-1]

5. 举例推导 dp 数组

  • 当 nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4] 时：
    • dp[0] = -2
    • dp[1] = max(-2+1, 1) = 1
    • dp[2] = max(1-3, -3) = -2
    • dp[3] = max(-2+4, 4) = 4
    • dp[4] = max(4-1, -1) = 3
    • dp[5] = max(3+2, 2) = 5
    • dp[6] = max(5+1, 1) = 6
    • 最终答案：6（子数组 [4,-1,2,1]）

152. 乘积最大子数组

题目链接：152. 乘积最大子数组

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • maxP[i]：以 nums[i] 结尾的最大乘积子数组
  • minP[i]：以 nums[i] 结尾的最小乘积子数组（负数可能变正）

2. 确定递推公式

  • 当前元素乘以之前的最大值/最小值，或从当前元素重新开始
  • maxP[i] = max(maxP[i-1] * nums[i], minP[i-1] * nums[i], nums[i])
  • minP[i] = min(maxP[i-1] * nums[i], minP[i-1] * nums[i], nums[i])

3. dp 数组的初始化

  • maxP[0] = nums[0]
  • minP[0] = nums[0]

4. 确定遍历顺序

  • 从前往后遍历，需要同时维护 maxP 和 minP

5. 举例推导 dp 数组

  • 当 nums = [2, 3, -2, 4] 时：
    • maxP[0] = 2, minP[0] = 2, ans = 2
    • maxP[1] = max(2*3, 2*3, 3) = 6, minP[1] = 3, ans = 6

32. 最长有效括号

题目链接：32. 最长有效括号

  • dp[i]：以 s[i] 结尾的最长有效括号长度

2. 确定递推公式

  • 当 s[i] == ')' 且 s[i-1] == '(' 时：dp[i] = dp[i-2] + 2
  • 当 s[i] == ')' 且 s[i-1] == ')' 时：
    • 如果 s[i - dp[i-1] - 1] == '('，则 dp[i] = dp[i-1] + dp[i - dp[i-1] - 2] + 2

3. dp 数组的初始化

  • dp[i] = 0：初始所有位置为0

4. 确定遍历顺序

  • 从左到右遍历字符串

5. 举例推导 dp 数组

  • 当 s = "(()())" 时：
    • dp[0] = 0
    • dp[1] = 0（s[1]=’(‘, 无法形成有效括号）
    • dp[2] = dp[0] + 2 = 2（s[1]=’(‘, s[2]=’)’）
    • dp[3] = 0（s[3]=’(‘）
    • dp[4] = dp[2] + 2 = 4（s[3]=’(‘, s[4]=’)’）
    • dp[5] = dp[4] + dp[1] + 2 = 6（s[4]=’)’, s[5]=’)’, s[5-4-1]=s[0]=’(‘）
    • 最终答案：6

  1. 使用栈保存未配对的左括号下标
  2. 遇到右括号时，弹出栈顶左括号下标，标记这两个位置为有效配对

2. 确定递推公式

  • dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]

5. 最长回文子串

题目链接：5. 最长回文子串

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[l][r]：字符串 s 从索引 l 到 r 的子串是否是回文串

2. 确定递推公式

  • 如果 s[l] == s[r]：
    • 如果 r - l <= 2（长度为1或2），则是回文
    • 否则需要 dp[l+1][r-1] 为 true
  • dp[l][r] = (s[l] == s[r]) && (r - l <= 2 || dp[l+1][r-1])

3. dp 数组的初始化

  • dp[i][i] = true：单个字符是回文

4. 确定遍历顺序

  • 外层遍历右端点 r，内层遍历左端点 l（l < r）

5. 举例推导 dp 数组

  • 当 s = "babad" 时：
    • dp[0][0] = dp[1][1] = dp[2][2] = dp[3][3] = dp[4][4] = true
    • dp[0][1] = (b==a) = false
    • dp[1][2] = (a==b) = false
    • dp[0][2] = (b==b) && dp[1][1] = true（”bab”）
    • dp[1][3] = (a==a) && dp[2][2] = true（”aba”）
    • 最长回文子串：”bab” 或 “aba”

1143. 最长公共子序列

题目链接：1143. 最长公共子序列

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i][j]：text1 的前 i 个字符和 text2 的前 j 个字符的最长公共子序列长度

2. 确定递推公式

  • 如果 text1[i-1] == text2[j-1]：dp[i][j] = dp[i-1][j-1] + 1
  • 否则：dp[i][j] = max(dp[i-1][j], dp[i][j-1])

3. dp 数组的初始化

  • dp[i][0] = 0：空字符串与任何字符串的LCS长度为0
  • dp[0][j] = 0：任何字符串与空字符串的LCS长度为0

4. 确定遍历顺序

  • 从左上到右下，逐行逐列遍历

5. 举例推导 dp 数组

  • 当 text1 = "abcde", text2 = "ace" 时：
    • dp[0][*] = 0, dp[*][0] = 0
    • dp[1][1] = dp[0][0] + 1 = 1（a==a）
    • dp[1][2] = max(dp[0][2], dp[1][1]) = 1（a!=c）
    • dp[2][1] = max(dp[1][1], dp[2][0]) = 1（b!=a）
    • dp[3][2] = dp[2][1] + 1 = 2（c==c）
    • 最终 dp[5][3] = 3（LCS为”ace”）

72. 编辑距离

题目链接：72. 编辑距离

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i][j]：将 word1 的前 i 个字符转换为 word2 的前 j 个字符所需的最少操作次数

2. 确定递推公式

  • 如果 word1[i-1] == word2[j-1]：无需操作，dp[i][j] = dp[i-1][j-1]
  • 否则，取三种操作的最小值：
    • 替换：dp[i-1][j-1] + 1
    • 删除：dp[i-1][j] + 1
    • 插入：dp[i][j-1] + 1
  • dp[i][j] = min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1]) + 1

3. dp 数组的初始化

  • dp[i][0] = i：删除 word1 的前 i 个字符
  • dp[0][j] = j：插入 word2 的前 j 个字符

4. 确定遍历顺序

  • 从左上到右下，逐行逐列遍历

5. 举例推导 dp 数组

  • 当 word1 = "horse", word2 = "ros" 时：
    • dp[0][*] = [0, 1, 2, 3]
    • dp[*][0] = [0, 1, 2, 3, 4, 5]
    • dp[1][1] = min(0, 1, 1) + 1 = 1（h->r）
    • dp[5][3] = 3（最终答案）

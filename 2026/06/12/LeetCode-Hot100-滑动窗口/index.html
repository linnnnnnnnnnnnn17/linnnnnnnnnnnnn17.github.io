3. 无重复字符的最长子串

题目链接：3. 无重复字符的最长子串

用一个滑动窗口（HashSet<Character> window），维护一个无重复字符的子串，每次移动窗口，更新最大长度。

438. 找到字符串中所有字母异位词

题目链接：438. 找到字符串中所有字母异位词

cntP统计p中每个字符出现的次数，cntS统计s的长为 p.size() 的子串 t 中每个字符出现的次数。
滑动窗口，每次移动窗口，更新最大长度。
如果 cntP 和 cntS 相等，说明 t 是 p 的字母异位词，记录下 t 的起始位置。

Java

C++

Java与C++区别

特性 Java C++
数组初始化 new int[26] vector<int>(26, 0)
数组比较 Arrays.equals(arr1, arr2) arr1 == arr2 (直接比较)
获取字符 s.charAt(index) s[index]
添加元素 ans.add(val) ans.push_back(val)
字符串长度 s.length() s.size()
返回类型 List<Integer> vector<int>
集合初始化 必须显式 new ArrayList<>() 声明即默认初始化
头文件 无需import 需要#include <vector>

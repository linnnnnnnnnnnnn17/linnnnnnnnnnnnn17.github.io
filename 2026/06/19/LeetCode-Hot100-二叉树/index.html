94. 二叉树的中序遍历

题目链接：94. 二叉树的中序遍历

解题思路

核心思想：递归实现中序遍历，按照”左-根-右”的顺序访问节点。

算法流程：

  1. 递归终止条件：当前节点为空时返回
  2. 递归遍历左子树
  3. 访问当前节点（将值加入结果列表）
  4. 递归遍历右子树

关键点：

  • 中序遍历顺序：左子树 → 根节点 → 右子树
  • 使用成员变量存储结果，避免每次递归传参

104. 二叉树的最大深度

题目链接：104. 二叉树的最大深度

解题思路

核心思想：递归计算二叉树深度，当前节点深度 = max(左子树深度, 右子树深度) + 1。

算法流程：

  1. 递归终止条件：当前节点为空时返回0
  2. 递归计算左子树深度
  3. 递归计算右子树深度
  4. 返回两者最大值 + 1（当前节点）

关键点：

  • 叶子节点深度为1
  • 空树深度为0

101. 对称二叉树

题目链接：101. 对称二叉树

解题思路

核心思想：递归比较左右子树是否对称，需要比较外侧和内侧节点。

算法流程：

  1. 终止条件：
    • 左右都为空 → true
    • 一个为空一个不为空 → false
    • 值不相等 → false
  2. 递归比较外侧（左左 vs 右右）
  3. 递归比较内侧（左右 vs 右左）
  4. 返回两者都为true

关键点：

  • 对称条件：左子树的左 = 右子树的右，左子树的右 = 右子树的左
  • 需要同时比较外侧和内侧

543. 二叉树的直径

题目链接：543. 二叉树的直径

解题思路

核心思想：后序遍历计算每个节点的左右子树深度，直径 = 左深度 + 右深度。

算法流程：

  1. 递归终止条件：当前节点为空时返回-1（边数）
  2. 递归计算左子树深度
  3. 递归计算右子树深度
  4. 更新全局最大直径（左深度 + 右深度）
  5. 返回当前节点深度（max(左深度, 右深度) + 1）

关键点：

  • 直径是边数，不是节点数
  • 需要用全局变量记录最大直径
  • 后序遍历：先计算子树深度再更新答案

102. 二叉树的层序遍历

题目链接：102. 二叉树的层序遍历

解题思路

核心思想：层序遍历（BFS）按层访问二叉树节点，使用队列实现。

递归解法思路：

  1. 递归遍历，记录当前深度
  2. 如果结果列表大小等于当前深度，添加新的层列表
  3. 将当前节点值加入对应层
  4. 递归遍历左右子树，深度+1

迭代解法思路：

  1. 初始化队列，根节点入队
  2. 循环处理队列：
    • 记录当前层节点数（队列大小）
    • 遍历当前层所有节点
    • 节点出队，值加入结果
    • 左右子节点入队
  3. 返回结果

108. 将有序数组转换为二叉搜索树

题目链接：108. 将有序数组转换为二叉搜索树

解题思路

核心思想：分治法构建平衡二叉搜索树，每次选择中间元素作为根节点。

算法流程：

  1. 递归终止条件：左边界 >= 右边界时返回null
  2. 找到中间位置 mid = (left + right) / 2
  3. 以nums[mid]为根节点创建新节点
  4. 递归构建左子树（区间 [left, mid)）
  5. 递归构建右子树（区间 [mid+1, right)）
  6. 返回根节点

关键点：

  • 有序数组的中间元素作为根节点保证平衡
  • 左闭右开区间处理边界

98. 验证二叉搜索树

  1. 递归终止条件：当前节点为空时返回true

关键点：

  • 使用long类型避免int溢出问题

199. 二叉树的右视图

题目链接：199. 二叉树的右视图

解题思路

核心思想：层序遍历或优先右子树的DFS，记录每层最右侧节点。

递归解法思路：

  1. 优先遍历右子树，再遍历左子树
  2. 如果结果列表大小等于当前深度，添加当前节点值（说明是该层第一个访问的节点，即最右侧）
  3. 递归遍历右子树，深度+1
  4. 递归遍历左子树，深度+1

迭代解法思路：

  1. BFS层序遍历
  2. 每层从右到左入队
  3. 记录每层第一个节点（最右侧）

105. 从前序与中序遍历序列构造二叉树

题目链接：105. 从前序与中序遍历序列构造二叉树

解题思路

核心思想：前序遍历首元素是根节点，中序遍历中根节点左边是左子树，右边是右子树。

算法流程：

  1. 递归终止条件：数组为空时返回null
  2. 前序遍历首元素为根节点值
  3. 在中序遍历中找到根节点位置，确定左子树大小
  4. 递归构建左子树（前序[1, 1+leftSize]，中序[0, leftSize]）
  5. 递归构建右子树（前序[1+leftSize, n]，中序[leftSize+1, n]）
  6. 返回根节点

关键点：

  • 前序：根-左-右，中序：左-根-右
  • 需要查找根节点在中序数组中的位置

236. 二叉树的最近公共祖先

题目链接：236. 二叉树的最近公共祖先

解题思路

核心思想：后序遍历，自底向上查找两个节点的最近公共祖先。

算法流程：

  1. 递归终止条件：当前节点为空或等于p/q时返回当前节点
  2. 递归查找左子树中的p/q
  3. 递归查找右子树中的p/q
  4. 判断：
    • 左右都不为空：当前节点是LCA
    • 左不为空右为空：返回左子树结果
    • 右不为空左为空：返回右子树结果

关键点：

  • 后序遍历：先找子树再判断
  • LCA是左右子树分别包含p和q的第一个节点

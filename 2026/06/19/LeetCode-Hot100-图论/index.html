200. 岛屿数量

题目链接：200. 岛屿数量

解题思路

核心思想：遍历二维网格，遇到岛屿（’1’）就进行DFS/BFS，将整个岛屿标记为已访问，计数+1。

算法流程：

  1. 遍历整个网格，找到未访问的岛屿格子（grid[i][j] == ‘1’）
  2. 岛屿计数+1，从该位置开始DFS/BFS
  3. DFS/BFS将所有相邻的’1’格子标记为已访问
  4. 继续遍历，最终计数即为岛屿数量

关键点：

  • 使用visited数组或原地修改标记已访问
  • 四个方向遍历：上、下、左、右

695. 岛屿的最大面积

题目链接：695. 岛屿的最大面积

解题思路

核心思想：与岛屿数量类似，但需要计算每个岛屿的面积，返回最大面积。

算法流程：

  1. 遍历网格，找到未访问的陆地格子（grid[i][j] == 1）
  2. 从该位置开始DFS/BFS，统计岛屿面积（计数器count）
  3. 每次访问陆地格子count+1
  4. 更新最大面积 res = Math.max(res, count)
  5. 返回最大面积

关键区别：

  • 需要维护岛屿面积计数器
  • DFS/BFS中每次访问有效格子就count++
  • 最终返回最大岛屿面积

994. 腐烂的橘子

题目链接：994. 腐烂的橘子

解题思路

核心思想：多源BFS，从所有腐烂橘子同时开始向四周扩散，感染新鲜橘子，记录感染时间。

算法流程：

  1. 初始统计：将所有腐烂橘子（值为2）加入队列，时间记为0
  2. 统计新鲜橘子数量
  3. BFS多源扩散：
    • 取出当前腐烂橘子，向四个方向扩散
    • 如果相邻格子是新鲜橘子，则腐烂（值变为2），加入队列
    • 记录腐烂时间 = 当前时间 + 1
  4. BFS结束后：
    • 如果还有新鲜橘子未腐烂，返回-1
    • 否则返回最大感染时间

关键点：

  • 多源BFS：从多个起始点同时开始
  • 需要记录每个橘子腐烂的时间
  • 使用minute数组或队列层级记录时间

207. 课程表

题目链接：207. 课程表

解题思路

核心思想：拓扑排序（Kahn算法），检测有向图是否有环。

前置概念：

  • 入度：指向该节点的边的数量
  • 邻接表：记录每个节点的出边指向哪些节点

算法流程：

  1. 构建邻接表和入度表
  2. 将所有入度为0的节点加入队列（没有先修课程的课程）
  3. BFS：取出队首节点，计数+1
  4. 遍历该节点的所有后继节点，将其入度-1
  5. 如果后继节点入度变为0，加入队列
  6. 判断：如果遍历到的节点数等于总课程数，则无环；否则有环

关键点：

  • 拓扑排序前提是有向无环图（DAG）
  • 检测自环：课程a依赖课程a本身

210. 课程表 II

题目链接：210. 课程表 II

解题思路

核心思想：拓扑排序的变体，在检测是否有环的同时，记录拓扑排序的顺序（即课程学习顺序）。

与207题的区别：

  • 207题只需返回是否可行（boolean）
  • 210题需要返回具体的课程学习顺序（数组）

算法流程：

  1. 构建邻接表和入度表
  2. 将所有入度为0的节点加入队列
  3. BFS：取出队首节点，加入结果数组
  4. 遍历该节点的所有后继节点，将其入度-1
  5. 如果后继节点入度变为0，加入队列
  6. 返回结果数组（如果节点数等于总课程数，否则返回空数组）

关键点：

  • 结果数组记录的是拓扑排序的顺序
  • 每弹出一个节点就将其加入结果数组

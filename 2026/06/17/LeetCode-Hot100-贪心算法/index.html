121. 买卖股票的最佳时机

题目链接：121. 买卖股票的最佳时机

解题思路

贪心算法

核心思想：在遍历过程中，维护两个变量：

  • low：当前遇到的最低价格
  • ans：当前能获得的最大利润

算法流程：

  1. 初始化 low = Integer.MAX_VALUE，ans = 0
  2. 遍历每个价格：
    • 更新 low 为当前价格和 low 的较小值
    • 计算当前卖出的利润 price - low，更新 ans 为较大值
  3. 返回 ans

贪心选择：每一天都做出局部最优选择（在最低点买入），最终得到全局最优解。

动态规划

1. 确定 dp 数组的下标及含义

  • dp[i][0]：第 i 天持有股票时的最大利润
  • dp[i][1]：第 i 天不持有股票时的最大利润

2. 确定递推公式

  • 持有股票：dp[i][0] = max(dp[i-1][0], -prices[i])
    • 要么之前就持有，要么今天买入
  • 不持有股票：dp[i][1] = max(dp[i-1][1], dp[i-1][0] + prices[i])
    • 要么之前就不持有，要么今天卖出

3. dp 数组的初始化

  • dp[0][0] = -prices[0]：第0天买入股票，利润为负的股价
  • dp[0][1] = 0：第0天不持有股票，利润为0

4. 确定遍历顺序

  • 从第1天到第n-1天，顺序遍历

5. 举例推导 dp 数组

  • 当 prices = [7, 1, 5, 3, 6, 4] 时：
    • dp[0] = [-7, 0]
    • dp[1] = [-1, 0]
    • dp[2] = [-1, 4]
    • dp[3] = [-1, 4]
    • dp[4] = [-1, 5]
    • dp[5] = [-1, 5]
    • 最终答案：5

55. 跳跃游戏

题目链接：55. 跳跃游戏

解题思路

贪心算法

核心思想：维护当前能到达的最远位置 mx。

算法流程：

  1. 初始化 mx = 0
  2. 遍历每个位置 i：
    • 如果 i > mx，说明无法到达当前位置，返回 false
    • 更新 mx = max(mx, i + nums[i])
  3. 遍历完成后返回 true

贪心选择：每次更新能到达的最远位置，确保覆盖尽可能多的位置。

动态规划

1. 确定 dp 数组的下标及含义

  • dp[i]：能否到达第 i 个位置

2. 确定递推公式

  • 如果存在 j < i，使得 dp[j] = true 且 nums[j] >= i - j，则 dp[i] = true

3. dp 数组的初始化

  • dp[0] = true：起点一定可达

4. 确定遍历顺序

  • 从第1个位置到第n-1个位置，顺序遍历

5. 举例推导 dp 数组

  • 当 nums = [2, 3, 1, 1, 4] 时：
    • dp[0] = true
    • dp[1] = true（从0可到达）
    • dp[2] = true（从0可到达）
    • dp[3] = true（从1或2可到达）
    • dp[4] = true（从3可到达）
    • 最终答案：true

45. 跳跃游戏 II

题目链接：45. 跳跃游戏 II

解题思路

贪心算法

核心思想：采用”搭桥”策略，维护当前桥的右端点 curEnd 和下一座桥的最远右端点 nextEnd。

算法流程：

  1. 初始化 ans = 0，curEnd = 0，nextEnd = 0
  2. 遍历每个位置（不包括最后一个）：
    • 更新 nextEnd = max(nextEnd, i + nums[i])
    • 当到达当前桥的右端点时，必须建一座新桥：
      • curEnd = nextEnd
      • ans++
  3. 返回 ans

贪心选择：每次在当前桥的范围内选择能跳得最远的位置作为下一座桥的终点。

动态规划

1. 确定 dp 数组的下标及含义

  • dp[i]：到达第 i 个位置所需的最少跳跃次数

2. 确定递推公式

  • dp[i] = min(dp[j] + 1)，其中 j < i 且 nums[j] >= i - j

3. dp 数组的初始化

  • dp[0] = 0：起点不需要跳跃
  • dp[i] = n + 1：初始化为一个较大的值（不可达）

4. 确定遍历顺序

  • 从第1个位置到第n-1个位置，顺序遍历

5. 举例推导 dp 数组

  • 当 nums = [2, 3, 1, 1, 4] 时：
    • dp[0] = 0
    • dp[1] = dp[0] + 1 = 1
    • dp[2] = min(dp[0]+1, dp[1]+1) = 1
    • dp[3] = min(dp[1]+1, dp[2]+1) = 2
    • dp[4] = min(dp[2]+1, dp[3]+1) = 2
    • 最终答案：2

56. 合并区间

题目链接：56. 合并区间

解题思路

贪心算法

核心思想：按区间起点排序，然后依次合并重叠区间。

算法流程：

  1. 按区间起点升序排序
  2. 遍历每个区间：
    • 如果当前区间与结果列表中最后一个区间重叠，更新最后一个区间的右边界
    • 否则，将当前区间加入结果列表
  3. 返回结果列表

贪心选择：每次选择起点最小的区间进行合并，保证局部最优。

动态规划（区间DP）

1. 确定 dp 数组的下标及含义

  • dp[i][j]：区间 [i, j] 是否可以合并成一个区间

2. 确定递推公式

  • 如果存在 k，使得 dp[i][k] 和 dp[k+1][j] 都为 true，且两个区间重叠，则 dp[i][j] = true

3. dp 数组的初始化

  • dp[i][i] = true：单个区间本身就是一个合并后的区间

4. 确定遍历顺序

  • 按区间长度从小到大遍历

5. 举例推导 dp 数组

  • 当 intervals = [[1,3],[2,6],[8,10],[15,18]] 时：
    • dp[0][0] = dp[1][1] = dp[2][2] = dp[3][3] = true
    • dp[0][1] = true（[1,3]和[2,6]重叠）
    • dp[0][2] = false（合并后的[1,6]与[8,10]不重叠）
    • 最终合并结果：[[1,6],[8,10],[15,18]]

763. 划分字母区间

题目链接：763. 划分字母区间

解题思路

贪心算法

核心思想：先记录每个字母最后出现的位置，然后遍历字符串维护当前区间的最远右端点。

算法流程：

  1. 遍历字符串，记录每个字符最后出现的位置 last[c]
  2. 初始化 start = 0，end = 0
  3. 遍历字符串：
    • 更新 end = max(end, last[s[i]])
    • 当 i == end 时，找到一个分割点：
      • 记录区间长度 end - start + 1
      • 更新 start = end + 1
  4. 返回结果列表

贪心选择：每次在当前区间内找到最远的字符位置，确保该区间内所有字符都只出现在该区间。

动态规划

1. 确定 dp 数组的下标及含义

  • dp[i]：字符串前 i 个字符的最少分割数

2. 确定递推公式

  • 如果子串 s[j+1...i] 中的所有字符的最后出现位置都 <= i，则 dp[i] = min(dp[i], dp[j] + 1)

3. dp 数组的初始化

  • dp[0] = 0：空字符串不需要分割
  • dp[i] = i：最坏情况每个字符单独分割

4. 确定遍历顺序

  • 从第1个字符到第n个字符，顺序遍历

5. 举例推导 dp 数组

  • 当 s = "ababcbacadefegdehijhklij" 时：
    • dp[0] = 0
    • dp[8] = 1（”ababcbaca” 是一个区间）
    • dp[15] = 2（加上 “defegde”）
    • dp[22] = 3（加上 “hijhklij”）
    • 最终分割：[9, 7, 8]

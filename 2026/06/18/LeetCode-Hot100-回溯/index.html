46. 全排列

题目链接：46. 全排列

解题思路

核心思想：排列型回溯，使用 used 数组标记元素是否已使用。

算法流程：

  1. 初始化 used 数组，标记每个元素是否被使用
  2. 回溯函数：
    • 终止条件：path.size() == nums.length，收集结果
    • 遍历所有元素，跳过已使用的元素
    • 选择当前元素，标记为已使用，递归下一层
    • 回溯：取消标记，移除当前元素

排列与组合的区别：

  • 排列：每次从头开始遍历，需要 used 数组去重
  • 组合：从 startIndex 开始遍历，避免重复组合

47. 全排列 II

题目链接：47. 全排列 II

解题思路

核心思想：排列型回溯 + 剪枝去重，需要先排序。

去重逻辑：

  • used[i - 1] == true：同一树枝上 nums[i-1] 使用过（可以继续使用）
  • used[i - 1] == false：同一树层上 nums[i-1] 使用过（需要跳过）

算法流程：

  1. 先排序数组，使相同元素相邻
  2. 回溯时，如果当前元素与前一个相同且前一个在同一树层使用过，跳过

78. 子集

题目链接：78. 子集

解题思路

核心思想：子集型回溯，收集所有节点的结果。

算法流程：

  1. 每次进入回溯函数，先收集当前 path 到结果
  2. 从 startIndex 开始遍历，避免重复组合
  3. 选择当前元素，递归下一层（i + 1）
  4. 回溯：移除当前元素

子集与排列的区别：

  • 子集：收集所有节点，不需要终止条件判断
  • 排列：只收集叶子节点，需要判断 path.size() == nums.length

377. 组合总和 Ⅳ

题目链接：377. 组合总和 Ⅳ

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i]：凑成目标值 i 的排列个数

2. 确定递推公式

  • dp[i] += dp[i - num]，对于每个 num，如果 i >= num

3. dp 数组的初始化

  • dp[0] = 1：凑成目标值0有1种方法（不选任何数）

4. 确定遍历顺序

  • 排列问题：外层遍历背包（目标值），内层遍历物品（nums）
  • 与组合问题相反：组合是外层物品，内层背包

5. 举例推导 dp 数组

  • 当 nums = [1, 2, 3], target = 4 时：
    • dp[0] = 1
    • dp[1] = dp[0] = 1（选1）
    • dp[2] = dp[1] + dp[0] = 2（选1或2）
    • dp[3] = dp[2] + dp[1] + dp[0] = 4（选1,2,3）
    • dp[4] = dp[3] + dp[2] + dp[1] = 7
    • 最终答案：7

22. 括号生成

题目链接：22. 括号生成

解题思路

核心思想：回溯生成有效括号组合，维护左括号和右括号的数量。

有效括号条件：

  • 左括号数量 l < n 时可以添加左括号
  • 右括号数量 r < l 时可以添加右括号（保证有效）

算法流程：

  1. 终止条件：r == n，收集结果
  2. 如果 l < n，添加左括号，递归，回溯撤销
  3. 如果 r < l，添加右括号，递归，回溯撤销

解题思路

核心思想：DFS回溯搜索，标记已访问位置，四个方向探索。

算法流程：

  1. 遍历棋盘，找到与单词首字母相同的起点
  2. DFS搜索：

    • 标记当前位置为已访问（'0'）

    • 回溯：恢复原来的字符

131. 分割回文串

题目链接：131. 分割回文串

解题思路

核心思想：分割型回溯，枚举所有分割点，判断子串是否回文。

算法流程：

  1. 终止条件：startIndex == s.length()，收集结果
  2. 遍历分割点 i：
    • 如果 s[startIndex..i] 是回文，加入 path
    • 递归下一层（i + 1）
    • 回溯撤销

回文判断：双指针从两端向中间遍历，判断是否相等。

51. N 皇后

题目链接：51. N 皇后

解题思路

核心思想：N皇后问题，逐行放置皇后，检查列和对角线是否冲突。

冲突检查：

  • 正上方列：检查同一列是否有皇后
  • 左上对角线（45度）：检查左上方是否有皇后
  • 右上对角线（135度）：检查右上方是否有皇后

算法流程：

  1. 初始化棋盘，每行n个’.’表示空位
  2. 逐行放置皇后：
    • 遍历每一列，检查是否合法
    • 合法则放置皇后，递归下一行
    • 回溯撤销

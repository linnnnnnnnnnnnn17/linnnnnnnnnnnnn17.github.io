1. 多多的数字组合

描述

多多君最近在研究某种数字组合：
定义为：每个数字的十进制表示中(0~9)，每个数位各不相同且各个数位之和等于N。
满足条件的数字可能很多，找到其中的最小值即可。
多多君还有很多研究课题，于是多多君找到了你–未来的计算机科学家寻求帮助。

数据范围： 1≤n≤1000
进阶：空间复杂度 O(1) ，时间复杂度 O(n)
时间限制：C/C++ 1秒，其他语言2秒
空间限制：C/C++ 256M，其他语言512M

输入描述：

共一行，一个正整数N，如题意所示，表示组合中数字不同数位之和。
（1 <= N <= 1,000）

输出描述：

共一行，一个整数，表示该组合中的最小值。
如果组合中没有任何符合条件的数字，那么输出-1即可。

示例1

输入例子：
5
输出例子：
5
例子说明：
符合条件的数字有：5，14，23，32，41
其中最小值为5

示例2

输入例子：
12
输出例子：
39
例子说明：
符合条件的数字有：39，48，57，……
其中最小值为39

示例3

输入例子：
50
输出例子：
-1
例子说明：
没有符合条件的数字 (Ｔ▽Ｔ)

ACM模式完整代码

思路及必要说明

这道题的核心是找到各个数位互不相同且数位之和等于N的最小数字。

关键观察：

  1. 边界情况判断：

    • 如果N < 10，直接返回N，因为单个数字本身就是最小的解
    • 如果N > 45（1+2+3+4+5+6+7+8+9=45），返回-1，因为最多只能用9个不同的数字

  2. 贪心策略：

    • 要使数字最小，需要尽可能少的位数，并且高位数字尽可能小
    • 从9开始向下取数字，直到剩下的数值小于当前数字
    • 这样可以保证使用最少的位数组成数字

  3. 构造过程：

    • 例如N=12：先取9（12>9），剩余3；再取8（3<8）停止，将3放在前面
    • 得到字符串”93”，反转后为”39”，这就是最小的符合条件的数字

时间复杂度：O(n)，最多遍历9次
空间复杂度：O(1)，只使用常量空间

测试运行情况

通过全部用例
运行时间：2ms
占用内存：504KB

2. 多多的字符变换

描述

多多君最近在研究字符串之间的变换，可以对字符串进行若干次变换操作:

交换任意两个相邻的字符，代价为0。
将任意一个字符a修改成字符b，代价为 |a - b|（绝对值）。
现在有两个长度相同的字符串X和Y，多多君想知道，如果要将X和Y变成两个一样的字符串，需要的最少的代价之和是多少。

时间限制：C/C++ 1秒，其他语言2秒
空间限制：C/C++ 256M，其他语言512M

输入描述：

共三行，第一行，一个整数N，表示字符串的长度。
（1 <= N <= 2,000）
接下来两行，每行分别是一个字符串，表示字符串X和Y。
（字符串中仅包含小写字母）

输出描述：

共一行，一个整数，表示将X和Y变换成一样的字符串需要的最小的总代价。

示例1

输入例子：
4
abca
abcd
输出例子：
3
例子说明：
其中一种代价最小的变换方案：
都修改为abcd，那么将第一个字符串X最后一个字符a修改为d，代价为|a - d| = 3。

示例2

输入例子：
4
baaa
aabb
输出例子：
1
例子说明：
其中一种代价最小的变换方案：
首先将第一个字符串通过交换相邻的字符：baaa -> abaa -> aaba，代价为0。
然后将第二个字符串修改最后一个字符b：|b - a| = 1。
两个字符都修改为aaba，所以最小的总代价为1。

示例3

输入例子：
3
abc
xyz
输出例子：
69

ACM模式完整代码

思路及必要说明

这道题的核心是找到将两个字符串X和Y变换成相同字符串所需的最小代价。

关键观察：

  1. 交换操作代价为0：这意味着我们可以任意重排字符串中的字符，因为通过相邻交换可以实现任意排列，而代价为0
  2. 修改操作代价：将字符a改为字符b的代价是|a - b|，即它们的ASCII差值的绝对值

解题步骤：

  1. 统计字符频率：分别统计字符串X和Y中每个字符的出现次数
  2. 计算字符差值：将X和Y的字符频率相减，得到每个字符需要增加或减少的数量
  3. 贪心转化：从左到右遍历字符（从’a’到’z’），将多余的字符逐步转化为缺少的字符

转化策略：

  • 对于每个字符位置i，检查是否有多余（正数）或缺少（负数）
  • 将多余的字符转化为下一个字符j（j > i），代价为(j - i)乘以转化的字符数量
  • 这样可以保证每次转化都是最短路径，从而总代价最小

时间复杂度：O(n + 26^2)，主要是统计字符频率和26个字符之间的转化
空间复杂度：O(26)，只需要存储26个字母的频率信息

测试运行情况

通过全部用例
运行时间：3ms
占用内存：452KB

C++ 的 size_t 类型：超清晰讲解

一、一句话总结

size_t 是 C++ 标准定义的无符号整数类型，专门用来表示大小、长度、计数、数组下标，是所有容器和标准库都在用的「尺寸专用类型」。

二、核心特点

  1. 无符号（unsigned）

    • 永远 ≥ 0，不能表示负数
    • 这是最容易踩坑的点！

  2. 平台自适应大小

    • 32位系统：4字节（和 unsigned int 一样）
    • 64位系统：8字节（和 unsigned long long 一样）
    • 不用你关心系统位数，它自动适配

  3. 标准库到处都在用

你不需要记，直接用就行。

四、最常见用法

1. 表示长度/大小

2. 循环遍历数组/容器（推荐写法）

五、超级重要的坑（必看）

❌ 错误：不要用负数

因为无符号类型没有负数，溢出会变成最大值。

✅ 正确：只用来表示大小、长度、数量

六、和 int 的区别

类型 符号 用途 平台适配
int 有符号 普通数值、可正可负 固定4字节
size_t 无符号 尺寸、长度、计数 自适应32/64位

规则：

  • 表示大小/长度/个数 → 用 size_t
  • 表示普通数值、分数、负数 → 用 int

总结

  1. size_t = 无符号整数，专门存大小、长度、计数
  2. 32/64位系统自动适配，安全通用
  3. 标准库（vector/string/数组）全用它
  4. 不能存负数，这是最大坑点

C++ 里 ::、&、*、.、-> 怎么用

一、先一句话总览

  • ::：作用域解析 → 找类/命名空间里的东西
  • .：对象直接访问成员 → 对象.成员
  • ->：指针访问成员 → 指针->成员
  • *：解引用指针 → 拿到指针指向的对象
  • &：取地址 / 引用 → 拿到变量地址，或定义引用

它们的关系一句话：
指针用 ->，对象用 .，& 取地址变指针，* 解指针变对象，:: 管作用域。

二、逐个讲清楚用法 & 场景

1. :: 作用域解析符

什么时候用？

  • 访问命名空间里的东西
  • 访问类的静态成员
  • 在类外实现类的成员函数
  • 解决同名冲突

一句话：找“哪里的”东西，就用 ::

2. . 成员访问符（对象直接用）

什么时候用？

  • 变量是对象本身（不是指针）
  • 访问它的成员变量/成员函数

规则：对象直接用 .

3. -> 指针成员访问

什么时候用？

  • 变量是指向对象的指针
  • 访问它的成员

等价于：

*规则：指针一律用 ->，不要写 (p).

4. * 解引用（dereference）

什么时候用？

  • 把指针 → 变回它指向的对象
  • 用于指针、迭代器

一句话： 就是“打开指针，拿到里面的东西”*

5. & 取地址 / 定义引用

（1）取地址：把对象变指针

（2）定义引用（别名）

一句话：& 要么拿地址，要么做引用。

三、它们之间的联系（超级关键）

1. -> 本质就是 * + .

所以：

  • 指针 → 用 ->
  • 解引用后变成对象 → 用 .

2. & 生成指针，* 还原对象

3. . 和 -> 永远二选一

  • 是对象 → .
  • 是指针 → ->
    不可能同时用。

4. :: 跟它们无关

:: 只管“哪里的”，不管指针对象。

四、最经典对比示例（一看就懂）

五、最简单记忆口诀

  • 找哪里的：::
  • 对象点成员：.
  • 指针箭头成员：->
  • 指针变对象：*
  • 对象变指针/引用：&

C++ 符号优先级

一、核心结论（必须背下来）

:: 是 C++ 优先级最高的运算符
比 . / -> / * / & / ++ / () 全都高。

它没有更低的时候，永远第一。

二、完整优先级排行（从高到低）

你最常用的符号顺序是：

  1. :: 作用域解析（最高）
  2. () 函数调用、[] 数组下标
  3. -> . 成员访问
  4. ++ --
  5. * 解引用 / & 取地址
  6. 算术运算、比较运算
  7. 赋值运算

三、最关键的 3 条规则（实战必用）

1. :: 比 . 和 -> 更高

编译器理解顺序：

  1. 先找 A::obj
  2. 再访问 .func()

不会变成 A::(obj.func())
永远是 (A::obj).func()

2. :: 比 * 和 & 更高

意思是：
A 类里的成员函数 func，返回值是 int*

不会变成 (int*) A::func()

3. :: 比 ++ -- 更高

先取 A::x，再自增。

四、一句话总结（超级好记）

:: 最高 → 然后是 . / -> → 然后是 * / & → 然后才是其他运算

五、最容易混淆的对比（一看就懂）

最终极简口诀

:: 最牛，谁都比不过它！
先算 ::，再算 . ->，再算 * &，最后算其他。

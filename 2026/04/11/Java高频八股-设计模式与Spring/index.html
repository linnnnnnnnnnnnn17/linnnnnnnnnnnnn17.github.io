详细答案

一、单例模式（4 场被问）⭐⭐⭐⭐

单例模式：保证一个类只有一个实例，并提供全局访问点。

核心：

  • 私有构造方法
  • 返回唯一实例
  • 线程安全

静态内部类：定义在类内部的类，用 static 修饰。

特点：

  • 不依赖外部类实例创建
  • 可直接通过外部类访问
  • 利用 JVM 类加载机制保证线程安全

1.1 饿汉式（Eager Initialization）

特点：类加载时就创建，线程安全（JVM 保证）

缺点：启动慢，占用资源

1.2 懒汉式

特点：延迟加载，但 synchronized 影响性能（每次调用都加锁）

1.3 双重校验锁（DCL = Double Checked Locking）

特点：延迟加载 + 线程安全 + 高性能（锁 只在第一次检查时竞争）

1.4 静态内部类

原理：

  • 只有调用 getInstance() 才会加载 Holder 类
  • JVM 保证类加载过程线程安全
  • 无需 synchronized

1.5 单例模式的缺点

  1. 全进程共享：内存占用
  2. 扩展困难：无法继承
  3. 测试困难：无法 Mock
  4. 违反 DIP：全局状态

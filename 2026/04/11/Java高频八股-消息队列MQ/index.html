1.1 Kafka、RocketMQ、RabbitMQ 的核心区别

特性 Kafka RocketMQ RabbitMQ
定位 分布式日志系统 金融级消息中间件 企业级消息队列
吞吐量 百万级/秒 十万级/秒 万级/秒

可靠性 异步复制 同步复制 消息确认机制
顺序消息 支持分区顺序 支持全局顺序 支持单队列顺序
事务消息 支持（事务 API） 原生支持 支持
集群 ZK/ KRaft NameServer 集群模式
适用场景 日志收集、大数据 订单、交易 金融、ERP

原理：磁盘顺序写比随机写快很多，不用反复移动

Kafka 实现：追加写 log 文件，顺序写入磁盘

1.3 RabbitMQ 在什么场景更合适

场景：

  1. 低延迟场景：微秒级延迟，适合金融交易
  2. 灵活路由：复杂的 Exchange 路由规则
  3. 小流量场景：万级/秒以下
  4. 需要事务：原生事务支持
  5. 队列优先级：支持消息优先级

不适合：大数据量、日志收集场景

1.4 线程池和消息队列实现异步的区别

特性 线程池 消息队列
解耦 同一进程 不同进程/机器
可靠性 进程崩则丢 可持久化，重试
流量削峰 无 有
复杂度 低 高
延迟 低 有延迟

选择：

  • 同一服务内异步 → 线程池
  • 跨服务/需要可靠性 → MQ

REALHW138 小红的岁晚可可塔

题目链接：REALHW138 小红的岁晚可可塔

描述

除夕之夜，小红正在为年夜饭准备一道名为“岁晚可可塔”的创意甜品。这道甜品由 n 层厚度均匀的巧克力蛋糕叠成，每一层都加入了不同比例的可可粉或糖浆。
具体来说，第 i 层蛋糕有一个“甜度值” a[i] 。如果 a[i] >0，表示这一层口感香甜；如果 a[i] <0，则表示这一层由于可可含量过高而带有苦味。为了保证口感的连贯性，小红需要从这 n 层蛋糕中切出连续的非空区间 [l,r] 作为最终成品，使得这段蛋糕的甜度总和达到最大。
请你帮助小红计算出，在这 n 层蛋糕中，连续的一段蛋糕层所能达到的最大甜度总和是多少。

输入描述：

输入共包含两行：
第一行包含一个整数 n（1≦n≦1000），代表可可塔的总层数。
第二行包含 n 个整数 a[1], a[2], …, a[n]，用空格分隔，表示每一层蛋糕的甜度值。每个甜度值的范围为 [−100000,100000]。

输出描述：

输出一个整数，表示连续的一段蛋糕层能够达到的最大甜度总和。

示例1

输入：
7
2 -4 3 -1 2 -4 3

输出：
4

说明：

在样例中，n=7，各层的甜度值分别为 [2,−4,3,−1,2,−4,3]。

若选择第 3 层到第 5 层（对应的甜度值为 3,−1,2），其甜度总和为 3+(−1)+2=4。

经计算，这是所有连续方案中所能得到的最大甜度总和。

ACM模式完整代码

思路及必要说明

本题思路

显然，本题就是要求最大子数组和。
可用动态规划思想求解。

动态规划五部曲

1. 确定 dp 数组的下标及含义

dp[i] 就是以 i 为终点的最大子数组和

2. 确定递推公式

有两种情况，之前的子数组和 < 0，所以以当前元素为终点的最大子数组和就是a[i]。
否则就是前面的最大子数组和再加上当前元素。

3. dp 数组的初始化

由递推公式，dp[i]依赖于dp[i-1]，所以只需要初始化dp[0]即可，显然，只有一个元素时，最大子数组和就是其本身。故初始化为 dp[0] = a[0];

4. 确定遍历顺序

因为dp[i]依赖于dp[i-1]，所以从前向后遍历即可。

5. 举例推导 dp 数组

分析样例：a = [2,−4,3,−1,2,−4,3]

  • dp[0] = a[0] = 2
  • dp[1] = max(dp[0] + a[1], a[1]) = -2
  • dp[2] = max(dp[1] + a[2], a[2]) = 3
  • dp[3] = max(dp[2] + a[3], a[3]) = 2
  • dp[4] = max(dp[3] + a[4], a[4]) = 4
  • dp[5] = max(dp[4] + a[5], a[5]) = 0
  • dp[6] = max(dp[5] + a[6], a[6]) = 3

ans = max(dp) = 4，符合题意。

REALHW140 奶油蛋糕的进阶配方

题目链接：REALHW140 奶油蛋糕的进阶配方

描述

小红是一名甜品店店长，她计划通过制作一系列进阶蛋糕来提升自己的“甜度等级”。
目前共有 n 种蛋糕配方，每种蛋糕最多制作一次。对于第 i 种蛋糕，只有当小红当前的甜度等级不低于其制作门槛 x[i]时，才能开始制作。制作该蛋糕需要消耗 z[i]点体力，并在制作完成后使小红的甜度等级提升 y[i] 点。
小红初始的甜度等级为 w，总体力值为 e。由于精力有限，她最多只能制作 k 个蛋糕。请问在体力允许且制作数量不超过 k 的前提下，小红最终能达到的最大甜度等级是多少？如果有多种方案能达到该最大等级，请输出达成该等级所需制作的最少蛋糕数量。

输入描述:

第一行包含四个整数 n, w, e, k，分别表示蛋糕的种类数、初始甜度等级、初始体力值以及最大制作数量。
第二行包含 n 个整数，表示每种蛋糕的制作门槛 x[i]。
第三行包含 n 个整数，表示每种蛋糕提升的甜度值 y[i]。
第四行包含 n 个整数，表示每种蛋糕消耗的体力值 z[i]。

数据范围：

  • 5 ≦ n ≦100
  • 0 ≦ w ≦1000
  • 0 ≦ e ≦80000
  • 1 ≦ k ≦n
  • 0 ≦ x[i], y[i] ≦10^6
  • 1 ≦ z[i] ≦80000

输出描述:

输出两个整数，用空格隔开。第一个整数表示能达到的最大甜度等级，第二个整数表示达到该等级所需制作的最少蛋糕数量。

示例1

输入
5 0 100 3
0 5 5 8 9
5 3 4 10 6
10 20 30 40 50
输出
19 3
说明

在样例中，小红可以按照以下顺序制作蛋糕：

1. 制作第 1 种蛋糕（门槛 latex）：消耗 10 体力，甜度变为 latex，剩余体力 90。

2. 制作第 3 种蛋糕（门槛 latex）：消耗 30 体力，甜度变为 latex，剩余体力 60。

3. 制作第 4 种蛋糕（门槛 latex）：消耗 40 体力，甜度变为 latex，剩余体力 20。

此时共制作 3 个蛋糕（未超过 latex），最终甜度等级为 19。这是该配置下能达到的最大值。

思路及必要说明

贪心为什么不能AC

核心问题分析

这道题的本质是：有依赖的背包问题。每个蛋糕的”解锁”依赖于当前甜度等级 w，w 越大，能做的蛋糕越多。

贪心算法的问题在于：

  1. 只看眼前利益：按 y 从大到小排序，选择高收益蛋糕，但忽略了体力消耗 z 和门槛 x 的影响

  2. 不考虑后续影响：选择高 y 蛋糕可能消耗大量体力，导致后续无法制作其他蛋糕

  3. 忽视动态门槛：门槛 x 是动态变化的——做完一个蛋糕后 w 增加，原来不能做的蛋糕可能变得能做

反例说明

贪心与动态规划对比

特性 贪心 动态规划
选择依据 当前最高y 全局最优
体力考虑 不考虑 精确计算
门槛依赖 静态处理 动态转移
最优解保证 无 有

关键矛盾：本题存在”先做低收益蛋糕 → 解锁高收益蛋糕”的路径依赖，这正是贪心的死穴。动态规划通过枚举所有可能的选择，解决了这个依赖问题。

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • 二维 dp 数组：dp[j][h] 表示制作 j 个蛋糕、消耗 h 体力后能达到的最大甜度等级
  • 下标范围：j ∈ [0, k]，h ∈ [0, e]
  • 初始值：-1 表示不可达状态

2. 确定递推公式

条件：

  • dp[j-1][h-z[i]] >= x[i] （当前甜度满足门槛）
  • dp[j-1][h-z[i]] != -1 （上一状态可达）

3. dp 数组的初始化

  • dp[0][0] = w （不制作任何蛋糕，消耗0体力，保持初始甜度）
  • 其余所有状态初始化为 -1 （不可达）

4. 确定遍历顺序

  • 外层循环：遍历每个蛋糕 i ∈ [0, n)
  • 中层循环：j 从 min(i+1, k) 倒序到 1（防止重复选取）
  • 内层循环：h 从 e 倒序到 z[i]（保证每个蛋糕只取一次）
  • 为什么倒序：01背包问题，每个蛋糕只能选一次，倒序避免状态污染

5. 举例推导 dp 数组

以示例1为例：

按门槛排序后：

关键状态演变：

  • i=0 (x=0, y=5, z=10)：dp[1][10] = max(-1, 0+5) = 5
  • i=1 (x=5, y=3, z=20)：dp[1][20]=3, dp[2][30]=8 (从dp[1][10]转移)
  • i=2 (x=5, y=4, z=30)：dp[1][30]=4, dp[2][40]=9, dp[3][70]=9
  • i=3 (x=8, y=10, z=40)：dp[2][50]=10, dp[3][80]=14
  • i=4 (x=9, y=6, z=50)：dp[3][90]=16 -> 最大19

最终遍历 dp 数组找到最大值和最小 j 即为答案。

复杂度

  • 时间复杂度：O(n × k × e)

    • 外层循环 n 次
    • 中层循环 k 次
    • 内层循环 e 次
    • 每次 O(1) 更新

  • 空间复杂度：O(k × e)

    • 二维 dp 数组 (k+1) × (e+1)

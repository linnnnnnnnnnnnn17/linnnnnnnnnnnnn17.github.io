必备知识补充

sstream 头文件

#include <sstream> 提供字符串流处理功能，常用类：

  • stringstream: 可像流一样读写字符串
  • ostringstream: 将数据格式化为字符串
  • istringstream: 从字符串解析数据

常用场景：字符串与数值转换、分割字符串、按格式输出

regex 头文件

#include <regex> 提供正则表达式功能，常用类：

  • regex: 编译正则表达式
  • smatch: 匹配结果

常用场景：字符串匹配、替换、提取

文本编辑器（支持撤销/重做）（2 场被问）⭐⭐⭐⭐

不是纯算法，考的是数据结构设计能力。需要用双栈实现 undo/redo，还要按文件路径分组管理。

题目描述：

设计一个支持撤销和重做的文本编辑器，支持以下操作：

  • type(word): 追加字符串 word 到当前光标位置
  • delete(k): 删除光标前 k 个字符
  • undo(): 撤销上一次操作
  • redo(): 重做被撤销的操作

每个操作需要记录操作的详细内容以支持撤销/重做，且需要按文件路径分组管理不同的编辑器实例。

示例：

输入：
[“Editor”,”type”,”type”,”delete”,”undo”,”redo”,”undo”]
[“”,[“a”],”ab”,”1”],[],[],[]]
输出：
[null,”a”,”ab”,”a”,”ab”,”a”,”ab”]

详细思路：

  1. 双栈结构：使用 undoStack 和 redoStack 两个栈，undoStack 存储每次操作前的状态，redoStack 存储被撤销的操作
  2. type 操作：保存当前状态到 undoStack，追加内容，清空 redoStack
  3. delete 操作：保存当前状态到 undoStack，删除指定长度，清空 redoStack
  4. undo 操作：将当前状态移到 redoStack，从 undoStack 恢复上一次状态
  5. redo 操作：将当前状态移到 undoStack，从 redoStack 恢复被撤销的状态

设计 Insert/Remove/GetRandom 均为 O(1) 的数据结构（1 场被问）⭐⭐⭐⭐

ArrayList + HashMap 的经典组合，考察对数据结构底层的理解。

题目描述：

设计一个数据结构，支持以下操作且均为 O(1) 时间复杂度：

  • insert(val): 插入一个元素 val（假设不重复）
  • remove(val): 删除一个元素 val
  • getRandom(): 随机返回一个元素

示例：

输入：
[“RandomizedSet”,”insert”,”remove”,”insert”,”getRandom”,”remove”,”insert”,”getRandom”]
[ [],[1],[2],[2],[],[1],[2],[] ]

输出：
[null,true,false,true,2,true,false,2]

详细思路：

  1. ArrayList + HashMap 组合：

    • vec 存储所有元素，用于 O(1) 随机访问
    • pos 哈希表存储 val -> index 映射，用于 O(1) 查找和删除

  2. insert: 检查是否存在，不存在则添加到 vec 末尾，记录位置

  3. remove:

    • 用要删除元素的位置与末尾元素交换
    • 更新末尾元素的新位置
    • 删除末尾元素，实现 O(1) 删除

  4. getRandom: 随机取 vec 中的一个元素

两个栈实现最大栈（获取最大值 O(1)）（1 场被问）⭐⭐⭐

辅助栈的经典应用。追问：只用一个栈怎么做？

题目描述：

设计一个支持 push ，pop ，top 操作，并能在常数时间内检索到最大元素的栈。

实现 MaxStack 类:

MaxStack() 初始化堆栈对象。
void push(int val) 将元素val推入堆栈。
void pop() 删除堆栈顶部的元素。
int top() 获取堆栈顶部的元素。
int getMax() 获取堆栈中的最大元素。

示例 1：

输入：
[“MaxStack”,”push”,”push”,”push”,”getMax”,”pop”,”top”,”getMax”]
[ [],[-2],[0],[-3],[],[],[],[] ]

输出：
[null,null,null,null,-3,null,0,-2]

解释：
MaxStack maxStack = new MaxStack();
maxStack.push(-2);
maxStack.push(0);
maxStack.push(-3);
maxStack.getMax(); –> 返回 -3.
maxStack.pop();
maxStack.top(); –> 返回 0.
maxStack.getMax(); –> 返回 -2.

提示：

-2^31 <= val <= 2^31 - 1
pop、top 和 getMax 操作总是在 非空栈 上调用
push, pop, top, and getMax最多被调用 3 * 10^4 次

详细思路：

  1. 双栈结构：

    • dataStack: 存储所有数据
    • maxStack: 存储当前位置的最大值，与 dataStack 同步

  2. push: 元素入 dataStack，同时更新 maxStack（当前最大值入栈）

  3. pop: 同时弹出两个栈的栈顶元素

  4. top: 返回 dataStack 栈顶

  5. getMax: 返回 maxStack 栈顶，即当前最大值

追问：只用一个栈怎么做？

  • 将当前最大值和实际值压入栈顶，例如 {-3, -3} 表示值为 -3，最大值为 -3
  • 每次 push 时比较当前值与栈顶最大值，压入 {val, max}

LC 300 最长递增子序列8次

题目链接：LC 300 最长递增子序列

题目描述

给你一个整数数组 nums ，找到其中最长严格递增子序列的长度。

子序列 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，[3,6,2,7] 是数组 [0,3,1,6,2,2,7] 的子序列。

示例 1：

输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。

示例 2：

输入：nums = [0,1,0,3,2,3]
输出：4

示例 3：

输入：nums = [7,7,7,7,7,7,7]
输出：1

提示：

1 <= nums.length <= 2500
-10^4 <= nums[i] <= 10^4

进阶：

你能将算法的时间复杂度降低到 O(n log(n)) 吗?

ACM完整代码

思路及必要说明

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i] 表示以 nums[i] 结尾的最长严格递增子序列的长度
  • 注意：必须以 nums[i] 结尾，这样才能保证递推的正确性

2. 确定递推公式

  • 对于每个 i，遍历所有 j < i
  • 如果 nums[i] > nums[j]，说明可以将 nums[i] 接在以 nums[j] 结尾的子序列后面
  • 递推公式：dp[i] = max(dp[i], dp[j] + 1)

3. dp 数组的初始化

  • 每个元素本身就是一个长度为 1 的子序列
  • 初始化：dp[i] = 1 for all i

4. 确定遍历顺序

  • 外层：从左到右遍历 i（0 → n-1）
  • 内层：从左到右遍历 j（0 → i-1）
  • 原因：计算 dp[i] 需要用到前面所有 dp[j] 的值

5. 举例推导 dp 数组（nums = [10,9,2,5,3,7,101,18]）

算法流程图：

复杂度分析：

  • 时间复杂度：O(n²)，双重循环
  • 空间复杂度：O(n)，dp数组

设计亮点：

  • dp[i] 定义为以 nums[i] 结尾的最长递增子序列，保证了递推的正确性
  • 使用 ans 变量实时更新最大值，避免最后再遍历dp数组

LC 53 最大子数组和 7次

题目链接：LC 53 最大子数组和

题目描述

给你一个整数数组 nums ，请你找出一个具有最大和的连续子数组（子数组最少包含一个元素），返回其最大和。

子数组是数组中的一个连续部分。

示例 1：

输入：nums = [-2,1,-3,4,-1,2,1,-5,4]
输出：6
解释：连续子数组 [4,-1,2,1] 的和最大，为 6 。

示例 2：

输入：nums = [1]
输出：1

示例 3：

输入：nums = [5,4,-1,7,8]
输出：23

提示：

1 <= nums.length <= 10^5
-10^4 <= nums[i] <= 10^4

进阶：如果你已经实现复杂度为 O(n) 的解法，尝试使用更为精妙的 分治法 求解。

贪心(仅核心代码)

思路及必要说明

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i] 表示以 nums[i] 结尾的连续子数组的最大和
  • 注意：必须以 nums[i] 结尾，保证连续性

2. 确定递推公式

  • 对于每个位置 i，有两种选择：
    1. 将 nums[i] 加入前面的子数组：dp[i-1] + nums[i]
    2. 以 nums[i] 重新开始一个新的子数组：nums[i]
  • 递推公式：dp[i] = max(dp[i-1] + nums[i], nums[i])

3. dp 数组的初始化

  • dp[0] = nums[0]，第一个元素本身就是一个子数组

4. 确定遍历顺序

  • 从左到右遍历 i（1 → n-1）
  • 原因：计算 dp[i] 只需要 dp[i-1] 的值

5. 举例推导 dp 数组（nums = [-2,1,-3,4,-1,2,1,-5,4]）

动态规划流程图：

贪心算法思路

核心思想：利用前缀和与前缀最小值的差值来找到最大子数组和

关键公式：

  • 前缀和：pre_sum[i] = nums[0] + nums[1] + ... + nums[i]
  • 子数组 [j+1, i] 的和 = pre_sum[i] - pre_sum[j]
  • 要最大化这个差值，需要最小化 pre_sum[j]（j < i）

贪心流程图：

复杂度分析：

  • 时间复杂度：O(n)，两种方法都是线性遍历
  • 空间复杂度：DP方法 O(n)，贪心方法 O(1)

设计亮点：

  • DP方法：max(dp[i-1]+nums[i], nums[i]) 巧妙地决定是否开始新子数组
  • 贪心方法：将问题转化为寻找前缀和的最大差值，空间复杂度优化到O(1)

题目链接：LC 55 跳跃游戏

题目描述

给你一个非负整数数组 nums ，你最初位于数组的 第一个下标 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 true ；否则，返回 false 。

示例 1：

输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。

示例 2：

输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0 ， 所以永远不可能到达最后一个下标。

提示：

1 <= nums.length <= 10^4
0 <= nums[i] <= 10^5

2. 确定递推公式

  • 如果存在 j < i，使得 dp[j] == true 且 nums[j] >= i - j
  • 则 dp[i] = true，否则 dp[i] = false

  • dp[0] = true，起点一定可以到达

贪心算法思路

关键观察：

  • 如果当前位置 i 在 mx 范围内，则可以从 i 跳到 i + nums[i]
  • 如果 i > mx，说明无法到达 i，直接返回 false

LC 64 最小路径和 6次

题目链接：LC 64 最小路径和

题目描述

给定一个包含非负整数的 m x n 网格 grid ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

说明：每次只能向下或者向右移动一步。

示例 1：

输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。

示例 2：

输入：grid = [[1,2,3],[4,5,6]]
输出：12

提示：

m == grid.length
n == grid[i].length
1 <= m, n <= 200
0 <= grid[i][j] <= 200

ACM完整代码

思路及必要说明

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i][j] 表示从左上角 (0,0) 走到 (i,j) 的最小路径和

2. 确定递推公式

  • 只能从上方 (i-1,j) 或左方 (i,j-1) 到达 (i,j)
  • 递推公式：dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + grid[i][j]

3. dp 数组的初始化

  • 第一行：只能从左边来，dp[0][j] = dp[0][j-1] + grid[0][j]
  • 第一列：只能从上面来，dp[i][0] = dp[i-1][0] + grid[i][0]
  • dp[0][0] = grid[0][0]

4. 确定遍历顺序

  • 先初始化第一行和第一列
  • 然后按行优先遍历，从 (1,1) 开始
  • 原因：计算 dp[i][j] 需要 dp[i-1][j] 和 dp[i][j-1]

5. 举例推导 dp 数组（grid = [[1,3,1],[1,5,1],[4,2,1]]）

算法流程图：

复杂度分析：

  • 时间复杂度：O(m×n)，遍历整个网格
  • 空间复杂度：O(m×n)，dp数组

设计亮点：

  • 直接在原grid上修改可以将空间复杂度优化到O(1)（如果允许修改输入）
  • 递推公式清晰，每个位置只依赖上方和左方的值

LC 70 爬楼梯 6次

题目链接：LC 70 爬楼梯

题目描述

假设你正在爬楼梯。需要 n 阶你才能到达楼顶。

每次你可以爬 1 或 2 个台阶。你有多少种不同的方法可以爬到楼顶呢？

示例 1：

输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。

  1. 1 阶 + 1 阶
  2. 2 阶

示例 2：

输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。

  1. 1 阶 + 1 阶 + 1 阶
  2. 1 阶 + 2 阶
  3. 2 阶 + 1 阶

提示：

1 <= n <= 45

ACM完整代码

思路及必要说明

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i] 表示爬到第 i+1 阶楼梯的方法数（注意：代码中dp[0]对应1阶）
  • 或者理解为：dp[i] 表示爬到第 i 阶的方法数（需要调整索引）

2. 确定递推公式

  • 最后一步可以是1阶或2阶
  • 如果最后一步是1阶，前面需要爬 n-1 阶
  • 如果最后一步是2阶，前面需要爬 n-2 阶
  • 递推公式：dp[i] = dp[i-1] + dp[i-2]

3. dp 数组的初始化

  • dp[0] = 1（1阶楼梯：只有1种方法）
  • dp[1] = 2（2阶楼梯：1+1 或 2）

4. 确定遍历顺序

  • 从左到右遍历 i（2 → n-1）
  • 原因：计算 dp[i] 需要 dp[i-1] 和 dp[i-2]

5. 举例推导 dp 数组（n = 5）

算法流程图：

复杂度分析：

  • 时间复杂度：O(n)，线性遍历

设计亮点：

  • 这是斐波那契数列的变形
  • 可以优化空间复杂度到O(1)，只保存前两个值

LC 406 根据身高重建队列 5次

题目链接：LC 406 根据身高重建队列

题目描述

假设有打乱顺序的一群人站成一个队列，数组 people 表示队列中一些人的属性（不一定按顺序）。每个 people[i] = [hi, ki] 表示第 i 个人的身高为 hi ，前面 正好 有 ki 个身高大于或等于 hi 的人。

请你重新构造并返回输入数组 people 所表示的队列。返回的队列应该格式化为数组 queue ，其中 queue[j] = [hj, kj] 是队列中第 j 个人的属性（queue[0] 是排在队列前面的人）。

示例 1：

输入：people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]
输出：[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]
解释：
编号为 0 的人身高为 5 ，没有身高更高或者相同的人排在他前面。
编号为 1 的人身高为 7 ，没有身高更高或者相同的人排在他前面。
编号为 2 的人身高为 5 ，有 2 个身高更高或者相同的人排在他前面，即编号为 0 和 1 的人。
编号为 3 的人身高为 6 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。
编号为 4 的人身高为 4 ，有 4 个身高更高或者相同的人排在他前面，即编号为 0、1、2、3 的人。
编号为 5 的人身高为 7 ，有 1 个身高更高或者相同的人排在他前面，即编号为 1 的人。
因此 [[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]] 是重新构造后的队列。

示例 2：

输入：people = [[6,0],[5,0],[4,0],[3,2],[2,2],[1,4]]
输出：[[4,0],[5,0],[2,2],[3,2],[1,4],[6,0]]

提示：

1 <= people.length <= 2000
0 <= hi <= 10^6
0 <= ki < people.length
题目数据确保队列可以被重建

ACM完整代码

思路及必要说明

核心思想：贪心算法，先处理身高高的人，因为高个子的位置不会被矮个子影响。

关键观察：

  • 每个人的 ki 表示前面有 ki 个身高 >= hi 的人
  • 如果先安排高个子，矮个子的插入不会影响高个子的 ki 计数
  • 按身高降序排序，身高相同时按 ki 升序排序

算法流程（people = [[7,0],[4,4],[7,1],[5,0],[6,1],[5,2]]）：

步骤1：排序

步骤2：依次插入到指定位置

最终结果：[[5,0],[7,0],[5,2],[6,1],[4,4],[7,1]]

算法流程图：

复杂度分析：

  • 时间复杂度：O(n²)，排序O(nlogn) + n次插入（每次O(n)）
  • 空间复杂度：O(n)，队列空间

设计亮点：

  • 使用list而不是vector，因为list的插入效率更高（O(1)定位+O(1)插入）
  • 排序策略巧妙：先处理高个子，避免后续插入影响已排好的位置
  • ki值直接作为插入位置，无需额外计算

LC 72 编辑距离 5次

题目链接：LC 72 编辑距离

题目描述

给你两个单词 word1 和 word2， 请返回将 word1 转换成 word2 所使用的最少操作数 。

你可以对一个单词进行如下三种操作：

插入一个字符
删除一个字符
替换一个字符

示例 1：

输入：word1 = “horse”, word2 = “ros”
输出：3
解释：
horse -> rorse (将 ‘h’ 替换为 ‘r’)
rorse -> rose (删除 ‘r’)
rose -> ros (删除 ‘e’)

示例 2：

输入：word1 = “intention”, word2 = “execution”
输出：5
解释：
intention -> inention (删除 ‘t’)
inention -> enention (将 ‘i’ 替换为 ‘e’)
enention -> exention (将 ‘n’ 替换为 ‘x’)
exention -> exection (将 ‘n’ 替换为 ‘c’)
exection -> execution (插入 ‘u’)

提示：

0 <= word1.length, word2.length <= 500
word1 和 word2 由小写英文字母组成

ACM完整代码

思路及必要说明

动态规划五部曲

1. 确定 dp 数组的下标及含义

  • dp[i][j] 表示将 word1[0..i-1] 转换成 word2[0..j-1] 的最少操作数
  • 注意：dp数组比实际字符串长度多1，方便处理空字符串情况

2. 确定递推公式

三种操作：

  1. 插入：在 word1 中插入一个字符 → dp[i][j] = dp[i][j-1] + 1
  2. 删除：在 word1 中删除一个字符 → dp[i][j] = dp[i-1][j] + 1
  3. 替换：将 word1[i-1] 替换为 word2[j-1] → dp[i][j] = dp[i-1][j-1] + 1
  • 如果 word1[i-1] == word2[j-1]，无需替换：dp[i][j] = dp[i-1][j-1]
  • 否则取三种操作的最小值：dp[i][j] = min(dp[i-1][j], dp[i][j-1], dp[i-1][j-1]) + 1

3. dp 数组的初始化

  • dp[i][0] = i：将 word1[0..i-1] 转换成空串需要删除i次
  • dp[0][j] = j：将空串转换成 word2[0..j-1] 需要插入j次

4. 确定遍历顺序

  • 按行优先遍历，从 (1,1) 开始
  • 原因：计算 dp[i][j] 需要 dp[i-1][j]、dp[i][j-1] 和 dp[i-1][j-1]

5. 举例推导 dp 数组（word1 = “horse”, word2 = “ros”）

算法流程图：

复杂度分析：

  • 时间复杂度：O(m×n)，m和n分别是两个字符串的长度
  • 空间复杂度：O(m×n)，dp数组

设计亮点：

  • dp数组比字符串长度多1，巧妙处理空字符串边界情况
  • 三种操作对应三种状态转移，逻辑清晰
  • 可以优化空间复杂度到O(min(m,n))，只保留当前行和上一行

35. 搜索插入位置

题目链接：35. 搜索插入位置

解题思路

核心思想：在有序数组中查找目标值，若不存在则返回插入位置。

算法流程：

  1. 初始化左右指针 l = 0, r = nums.length - 1
  2. 循环条件 l <= r：
    • 计算中点 mid = (l + r) / 2
    • 若 nums[mid] > target：目标在左半部分，r = mid - 1
    • 若 nums[mid] < target：目标在右半部分，l = mid + 1
    • 若相等：找到目标，返回 mid
  3. 循环结束时，l 即为插入位置（此时 l > r，nums[l-1] < target <= nums[l]）

关键点：

  • 二分查找的标准模板，适用于查找或确定插入位置
  • 时间复杂度：O(logn)，空间复杂度：O(1)

74. 搜索二维矩阵

题目链接：74. 搜索二维矩阵

解题思路

核心思想：将二维矩阵视为有序数组，先确定目标可能所在的行，再在该行中二分查找。

算法流程：

  1. 边界检查：若矩阵最小值 > target 或最大值 < target，直接返回false
  2. 遍历每一行，找到满足 matrix[i][0] <= target <= matrix[i][n-1] 的行
  3. 在该行中进行二分查找：
    • 初始化 l = 0, r = n - 1
    • 循环条件 l <= r，计算中点并比较
  4. 找到返回true，未找到返回false

关键点：

  • 矩阵每行有序，且下一行第一个元素大于等于上一行最后一个元素
  • 时间复杂度：O(m + logn)，空间复杂度：O(1)

34. 在排序数组中查找元素的第一个和最后一个位置

题目链接：34. 在排序数组中查找元素的第一个和最后一个位置

解题思路

核心思想：找到目标值在有序数组中的起始和结束位置。

两种解法思路：

1. 哈希表

  • 用HashMap记录每个元素出现的所有下标位置
  • 没出现直接返回{-1,-1}
  • 出现返回记录的头尾值
  • 时间复杂度：O(n)，空间复杂度：O(n)

2. 二分查找（推荐）

  • 实现lower_bound函数：返回第一个nums[i] >= target的下标
  • 查找target的起始位置：start = lower_bound(nums, target)
  • 若start == nums.length或nums[start] != target，说明target不存在
  • 查找target+1的起始位置：end = lower_bound(nums, target + 1) - 1
  • 时间复杂度：O(logn)，空间复杂度：O(1)

关键点：

  • lower_bound是二分查找的变种，查找第一个大于等于target的位置
  • 利用lower_bound(target+1)-1巧妙找到右边界

33. 搜索旋转排序数组

题目链接：33. 搜索旋转排序数组

解题思路

核心思想：旋转排序数组可以拆分为两个有序子数组，先找到旋转点k，再分别在两个有序区间二分查找。

两种解法思路：

1. 顺序查找k

  • 遍历数组找到旋转点k（nums[k] < nums[k-1]）
  • 在区间[0, k-1]和[k, n-1]分别二分查找target
  • 时间复杂度：O(n)，空间复杂度：O(1)

2. 二分查找k（推荐）

  • 使用二分查找快速定位旋转点k
  • 旋转点特点：nums[mid] > nums[r]说明旋转点在右半部分
  • 在两个有序区间分别二分查找target
  • 时间复杂度：O(logn)，空间复杂度：O(1)

关键点：

  • 旋转排序数组的特点：nums[0] > nums[n-1]（旋转过），nums[0] <= nums[n-1]（未旋转）
  • 旋转点k是数组的最小值位置

153. 寻找旋转排序数组中的最小值

题目链接：153. 寻找旋转排序数组中的最小值

解题思路

核心思想：找到旋转排序数组中的最小值，即旋转点。

两种解法思路：

1. 顺序查找

  • 遍历数组，找到第一个nums[i] < nums[i-1]的位置
  • 返回nums[i]，若未找到说明未旋转，返回nums[0]
  • 时间复杂度：O(n)，空间复杂度：O(1)

2. 二分查找（推荐）

  • 初始化l = 0, r = nums.length - 1
  • 循环条件l < r：
    • 计算mid = (l + r) / 2
    • 若nums[mid] > nums[r]：最小值在右半部分，l = mid + 1
    • 否则：最小值在左半部分或就是mid，r = mid
  • 循环结束时l == r，返回nums[l]
  • 时间复杂度：O(logn)，空间复杂度：O(1)

关键点：

  • 旋转排序数组的最小值一定是旋转点
  • 若数组未旋转（nums[0] < nums[n-1]），最小值就是nums[0]

4. 寻找两个正序数组的中位数

题目链接：4. 寻找两个正序数组的中位数

解题思路

核心思想：合并两个有序数组，排序后根据长度奇偶性返回中位数。

算法流程：

  1. 合并两个数组：
    • 创建新数组total，长度为len1 + len2
    • 将nums1复制到total前半部分
    • 将nums2复制到total后半部分
  2. 对合并后的数组排序
  3. 根据数组长度判断中位数：
    • 奇数长度：返回中间位置元素 total[n/2]
    • 偶数长度：返回中间两个元素的平均值 (total[n/2] + total[n/2-1]) / 2.0

关键点：

  • 时间复杂度：O((m+n)log(m+n))，主要由排序决定
  • 空间复杂度：O(m+n)，需要额外数组存储合并结果
  • 这是一种直观解法，虽然不是最优的O(log(m+n))二分查找解法，但实现简单易懂

关于System.arraycopy()方法的介绍

  • System.arraycopy()方法用于将一个数组的元素复制到另一个数组中。
  • 语法：System.arraycopy(源数组, 源数组起始索引, 目标数组, 目标数组起始索引, 复制元素个数)
  • 例如：System.arraycopy(nums1, 0, total, 0, len1) 将nums1的前len1个元素复制到total的前len1个位置。
  • 注意：System.arraycopy方法不会返回值，它直接在目标数组上修改元素。
